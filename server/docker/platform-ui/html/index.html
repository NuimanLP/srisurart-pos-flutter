หน้านี้ไม่มีการสร้างผู้ดูแลแพลตฟอร์มใหม่ — ใช้ CLI บนเซิร์ฟเวอร์เท่านั้น (No admin-creation page here — use the server CLI.)

สร้างร้านใหม่ (Create tenant)

ระบบจะสร้างรหัสผ่านชั่วคราวให้เจ้าของร้านเอง — ไม่มีช่องให้ตั้งรหัสผ่านที่นี่ (the server generates the owner's temporary password; there is no field to set one).

รายชื่อร้านทั้งหมด (Tenants)

รหัส ชื่อร้าน แผน สถานะ

สถานะปัจจุบัน:

ร้านนี้ปิดถาวรแล้ว — เปลี่ยนสถานะไม่ได้อีก

บัญชีเจ้าของร้าน (Owner account)

ใช้เมื่อเจ้าของร้านลืมรหัสผ่านเท่านั้น — ต้องโทรกลับไปที่เบอร์โทร/อีเมล ที่บันทึกไว้ตอนเปิดร้าน เพื่อยืนยันตัวตนก่อนเสมอ ห้ามเชื่อเบอร์/อีเมลที่ผู้โทรเข้ามาแจ้งเอง (call back the shop's phone/email on file to verify identity — never trust an inbound caller's own number).

อุปกรณ์ (Devices)

ID ป้ายชื่อ บทบาท สถานะการผูกเครื่อง

งานนำเข้าข้อมูลล่าสุด (Recent import jobs)

ID สถานะ สร้างเมื่อ เริ่ม เสร็จ ผล / ข้อผิดพลาด

เวลาทั้งหมดในหน้านี้เป็นเวลาไทย (Asia/Bangkok)

ใช้เมื่ออุปกรณ์นี้หายหรือถูกล้างข้อมูลเบราว์เซอร์ไปแล้วเท่านั้น — ระบบจะปลดอุปกรณ์นี้ทันที และสร้างอุปกรณ์ใหม่ (เลขเครื่องใหม่) พร้อมรหัสลงทะเบียนสำหรับผูกเครื่องใหม่

ข้อมูลนี้จะแสดงครั้งเดียวเท่านั้น — คัดลอกและส่งให้ร้านทันที (This information is shown once only — copy and hand it to the shop now.)
