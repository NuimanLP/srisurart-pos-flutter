Section 1

เข้าสู่ระบบ Login (API build)

เข้าสู่ระบบทุกเช้า — ระบบตั้งใจให้ session หมดอายุตอน 04:00 ทุกวัน ตามเวลาของร้าน (ADR-0009) ถ้าหมดอายุระหว่างใช้งาน ระบบจะพากลับมาหน้านี้เองโดยไม่มีข้อความเตือน

session หมดอายุตอนไหน
  • เข้าสู่ระบบก่อน 03:00 → ใช้ได้ถึง 04:00 ของเช้าวันนั้น · เข้าสู่ระบบหลัง 03:00 → ใช้ได้ถึง 04:00 ของวันถัดไป (ร้านที่เปิดตอนตีสามครึ่งจึงไม่ถูกเด้งออกในอีกครึ่งชั่วโมง)
  • ระหว่างวันระบบต่ออายุให้เองเบื้องหลัง ไม่ต้องทำอะไร
  • ร้านที่เปิดข้ามคืน: ตอน 04:00 จะกลับมาหน้าเข้าสู่ระบบ — ของในตะกร้าไม่หาย (ถ้าไม่ได้รีโหลดหน้าเว็บ) เข้าสู่ระบบใหม่แล้วขายต่อ ถ้าตอนนั้นเน็ตหลุดให้ใช้ PIN ออฟไลน์ (ด้านล่าง)
  • ส่งต่อเครื่องให้คนถัดไป: กด ออกจากระบบ เอง (ตั้งค่า → 🔐 บัญชี / ผูกเครื่อง) → ระบบล้างตะกร้าและใบเสนอราคาที่ค้างในตะกร้า และคนถัดไปเข้าสู่ระบบแล้วไปหน้า ขายสินค้า เสมอ · รายการที่รอส่งขึ้นเซิร์ฟเวอร์ (หัวข้อ 8) ไม่หาย · ต่างจาก session หมดอายุ ที่ตะกร้ายังอยู่และพากลับหน้าเดิม

ออนไลน์ — ใช้รหัสผ่าน Online

  1. ดูป้ายสถานะเครื่องเหนือฟอร์มต้องเป็น เครื่อง POS (มีสิทธิ์ขายและบันทึกเงินสด) ถ้าเห็น โหมด Backoffice (ยังไม่ได้ผูกเครื่อง POS) เครื่องนี้ยังขายไม่ได้ — แจ้งเจ้าของร้านให้ผูกเครื่อง (ภาค 02) · ถ้าเห็น ผูกเครื่องกับร้านแล้ว รอเข้าสู่ระบบเพื่อยืนยันสิทธิ์การใช้งาน แปลว่าเพิ่งผูกเครื่อง — เข้าสู่ระบบต่อได้เลย
  2. กรอก ชื่อผู้ใช้ (Username) และ รหัสผ่าน (Password)
  3. กด เข้าสู่ระบบหน้า ขายสินค้า และแถบเมนูเบราว์เซอร์อาจถามว่าจะบันทึกรหัสผ่านไหม — บันทึกได้บนเครื่องที่คนเดียวใช้ · เครื่องใช้ร่วมกันให้กด "ไม่" (ระบบไม่เสนอให้บันทึกรหัสผ่านชั่วคราวหรือรหัสที่ถูกปฏิเสธ)
ถ้าขึ้นหน้า "ตั้งรหัสผ่านใหม่"แปลว่ากำลังใช้รหัสผ่านชั่วคราว — เป็นงานของเจ้าของร้าน ดูภาค 02 หัวข้อ 1

ออฟไลน์ — ใช้ PIN Offline PIN

เมื่อเน็ตหลุด หน้าเข้าสู่ระบบบนเครื่อง POS ที่ตั้ง PIN ไว้แล้วจะขึ้น โหมดออฟไลน์: เข้าสู่ระบบหน้าร้านด้วย PIN 4-6 หลัก เพื่อขายของและบันทึกรายการ

  1. รอให้ระบบรู้ว่าเน็ตหลุดระบบตรวจการเชื่อมต่อทุก 5 วินาที — ฟอร์ม PIN ขึ้นเมื่อตรวจไม่ผ่านติดกัน 3 ครั้ง (ราว 15 วินาที) หรือทันทีที่เซิร์ฟเวอร์ตอบช้าเกิน 5 วินาที ถ้ายังเห็นช่องชื่อผู้ใช้/รหัสผ่าน ให้รอสักครู่
  2. กรอก รหัส PIN ออฟไลน์ (4-6 หลัก)PIN เดียวทั้งร้าน ผูกกับเครื่องนี้เท่านั้น
  3. กด เข้าสู่ระบบ (PIN ออฟไลน์)หน้าขาย พร้อมแถบสีเหลือง "ออฟไลน์ (ขายสำรอง)"
  4. เมื่อเน็ตกลับรายการที่ขายไว้ส่งขึ้นเซิร์ฟเวอร์เอง (หัวข้อ 8) — ลิงก์ เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน ใต้ปุ่มใช้สลับกลับไปฟอร์มรหัสผ่าน
ถ้าเห็นข้อความนี้หมายความว่า / ทำอย่างไร
เครื่องนี้ยังไม่ได้ตั้งค่า PIN ออฟไลน์ กรุณาเชื่อมต่ออินเทอร์เน็ตเพื่อเข้าสู่ระบบไม่ใช่เครื่อง POS หรือยังไม่ตั้ง PIN — รอเน็ตกลับ
ไม่สามารถใช้ PIN ออฟไลน์ได้เนื่องจากเกินกำหนด 3 วัน กรุณาเชื่อมต่ออินเทอร์เน็ตเพื่อเข้าสู่ระบบใหม่PIN ใช้ได้ 3 วันนับจากเข้าสู่ระบบออนไลน์ครั้งล่าสุด
เข้าสู่ระบบไม่สำเร็จเข้าสู่ระบบไม่ได้ (เช่น เครื่องอ่านข้อมูลที่เก็บไว้ไม่ได้) ระบบจะแจ้งข้อความนี้เสมอ ไม่หมุนค้าง — ลองกดใหม่ ถ้ายังไม่ได้ให้แจ้งเจ้าของร้าน
รหัส PIN ถูกล็อกเนื่องจากใส่ผิดครบ 5 ครั้ง กรุณาเชื่อมต่ออินเทอร์เน็ตเพื่อเข้าสู่ระบบด้วยรหัสผ่านหลักต้องเข้าด้วยรหัสผ่านตอนออนไลน์ แล้วให้เจ้าของร้านตั้ง PIN ใหม่

Section 2

เปิดกะ — ลิ้นชักเงินสด Open shift

ต้องเปิดกะก่อนขาย — ใน API build ถ้ายังไม่เปิดกะ กดชำระเงินจะขึ้น กรุณาเปิดกะก่อนขาย และรับชำระเครดิตช่างจะขึ้น กรุณาเปิดกะก่อนรับชำระ

  1. นับเงินทอนที่ใส่ลิ้นชัก
  2. กดเมนู ลิ้นชักยังไม่ได้เปิดร้านวันนี้ / กรอกเงินตั้งต้นในลิ้นชักก่อนเริ่มขาย
  3. กรอก เงินตั้งต้น ฿หรือกดปุ่มลัด ฿500 ฿1,000 ฿2,000 ฿3,000 (ต้องมากกว่า 0 ไม่เช่นนั้นขึ้น กรุณากรอกเงินตั้งต้นให้ถูกต้อง)
  4. กด เปิดร้าน2 แท็บ 💵 รายการเงิน / 🔒 ปิดลิ้นชัก และประวัติ เปิดร้าน {hh:mm} · ตั้งต้น {baht}
เปิดกะตอนเน็ตหลุดใน API build การเปิดกะและการบันทึกเงินเข้า-ออกทำได้ตอนออฟไลน์ — ระบบเก็บไว้ในเครื่องแล้วส่งขึ้นเซิร์ฟเวอร์เองเมื่อเน็ตกลับ
กะที่ไม่ได้ปิดถ้าลืมปิดกะ เมื่อเปิดกะใหม่ ระบบจะเก็บกะเก่าเข้าประวัติเองแบบ "ไม่ได้นับเงิน" และขึ้นให้เจ้าของร้านตรวจในหน้า รอเจ้าของ เป็นรายการ กะไม่ได้นับเงินสด — นับเงินและปิดกะทุกครั้งดีที่สุด

Section 3

ขายสินค้า Checkout

หน้าแรกของระบบ ซ้ายคือรายการสินค้า ขวาคือตะกร้าและการชำระเงิน (บนมือถือแยกเป็น 2 แท็บ สินค้า / ตะกร้า)

  1. เพิ่มสินค้ายิงบาร์โค้ด/พิมพ์รหัสในช่อง สแกนบาร์โค้ด / รหัสอะไหล่ แล้วกด Enter หรือค้นชื่อในช่อง ค้นหาชื่อสินค้า… แล้วแตะการ์ดสินค้า (กรองหมวดด้วยชิป ทั้งหมด ฯลฯ) สินค้าลงตะกร้า — ถ้ารหัสไม่มีจะขึ้น ไม่พบรหัส: {val}
  2. ปรับจำนวนขายเกินสต็อกไม่ได้: สต็อก "{name}" เหลือเพียง {stock} ชิ้น · การ์ดที่ขึ้น สินค้าหมด กดไม่ได้
  3. เลือกลูกค้า (ถ้ามี)ช่อง ลูกค้า ค้นด้วยชื่อหรือเบอร์ — ลูกค้าได้แต้ม 1 แต้มต่อทุก ฿10 (ปัดลง)
  4. เลือกช่าง (ถ้าเป็นงานช่าง)ช่อง 🔧 ช่าง (ปรับราคาช่าง) — ดูหัวข้อ 4
  5. ใส่ส่วนลด (ถ้ามี)ช่อง ส่วนลด — กดปุ่ม ฿ / % ข้างช่องเพื่อเลือกกรอกเป็นบาทหรือเปอร์เซ็นต์ (0–100) โหมด % ระบบคิดเป็นบาทให้และแสดงยอดใต้ช่อง ถ้าแก้ตะกร้ายอดส่วนลดจะคิดใหม่เอง (พักบิล/ใบเสนอราคาเก็บเป็นบาท) — เกินยอดรวมไม่ได้ (ส่วนลด {baht} เกินยอดรวม {baht})
  6. เลือกวิธีชำระเงินสด · โอน/QR · เครดิตช่าง (ขึ้นเฉพาะเมื่อเลือกช่าง)
  7. เงินสด: กรอกเงินที่รับช่อง รับเงิน ฿… หรือปุ่มลัด แถว เงินทอน — ถ้าเงินไม่พอกดขายจะขึ้น รับเงินไม่ครบ
  8. กด ชำระเงิน {baht}ระหว่างบันทึกปุ่มเป็น กำลังบันทึก…ใบเสร็จ (หัวข้อ 4)

อ่านการ์ดสินค้า · ดูรูปสินค้า Product card & picture

  • รูปอยู่ด้านบนของการ์ด — สินค้าที่เจ้าของร้านยังไม่ใส่รูปแสดงเป็นไอคอนบนพื้นสีอ่อนแทน (ไม่ใช่ข้อผิดพลาด) · รูปโหลดไม่ขึ้น (เน็ตช้า/หลุด) ก็ขึ้นไอคอนเช่นกัน
  • ป้ายหมวด อยู่มุมซ้ายบนของรูป · ⭐ สินค้าโปรด อยู่มุมขวาบน กดแล้วสลับเพิ่ม/เอาออกจากสินค้าโปรดเหมือนเดิม (ไม่เพิ่มลงตะกร้า)
  • ใต้รูป เรียงจากบนลงล่าง: รหัสสินค้า (ตัวเล็กสีจาง) · สถานะสต็อก มีสินค้า / สต็อกต่ำ / หมด · ชื่อสินค้า (ยาวเกิน 2 บรรทัดตัดด้วย …) · คงเหลือ {n} · ราคาตัวใหญ่ล่างสุด
  • ดูรูปขนาดใหญ่: สินค้าที่มีรูปจะมีปุ่มแว่นขยาย (ชี้ค้างจะขึ้น ดูรูป) ที่มุมขวาล่างของรูป → เปิดหน้าต่างรูปใหญ่ มีชื่อและรหัสสินค้า ใช้สองนิ้วถ่าง/เลื่อนเมาส์เพื่อซูมได้ → กด ปิด · ปุ่มนี้ไม่เพิ่มสินค้าลงตะกร้า
  • แตะส่วนอื่นของการ์ด = เพิ่มลงตะกร้าเหมือนเดิม · การ์ดสินค้าหมด (ม่านทับ สินค้าหมด) ยังกดเพิ่มไม่ได้ แต่ ⭐ ยังกดได้

เงินออกเกินเงินในลิ้นชักบันทึก 💸 เงินออก มากกว่าเงินที่มีในลิ้นชักไม่ได้ ระบบจะขึ้น เงินในลิ้นชักไม่พอ (มี ฿X) โดย ฿X คือเงินที่มีอยู่ตอนนี้ — ให้ลดจำนวนลง หรือบันทึก 💰 เงินเข้า ก่อนถ้าเติมเงินเข้าลิ้นชักจริง · เงินที่ควรมีในลิ้นชักนับ ตามกะ กะใหม่เริ่มนับจากเงินตั้งต้นของกะนั้น ไม่รวมเงินของกะก่อน · ถ้าบันทึกเงินออกตอนออฟไลน์แล้วพอส่งเข้าระบบ ยอดออกมากกว่าเงินในลิ้นชัก ระบบยังเก็บรายการไว้ และแจ้งเจ้าของร้านที่หน้า รอเจ้าของ (เงินออกจากลิ้นชักเกินยอดตอนออฟไลน์)

ปิดกะ Close shift

  1. ตรวจว่าไม่มีรายการค้างส่งป้ายมุมบนต้องเป็น ออนไลน์ ไม่มีตัวเลขค้าง (ดูหัวข้อ 8)
  2. แท็บ 🔒 ปิดลิ้นชัก — อ่าน "สรุปยอดเงินสด"เงินที่ควรมีในลิ้นชัก = ตั้งต้น + ขายเงินสด + รับชำระเครดิต (เงินสด) − คืนเงินสด + เงินเพิ่ม − เงินออก
  3. นับเงินจริง กรอก นับเงินสดจริงได้ ฿ผลต่าง: ✓ ตรงยอด / เงินเกิน +{baht} / เงินขาด −{baht}
  4. กด 🔒 ยืนยันปิดลิ้นชัก✓ ปิดลิ้นชักแล้วเวลา {hh:mm} · นับจริง {baht} — หลังจากนี้บันทึกเงินเข้า-ออกในกะนี้ไม่ได้แล้ว (ขายต่อ = เปิดกะใหม่ ด้านล่าง)
  5. (แนะนำ) พิมพ์สรุปยอดปุ่ม 📊 สรุปยอดปิดร้าน → 🖨 พิมพ์รายงานปิดร้าน
อ่านสรุปยอดปิดร้านส่วน วิธีชำระเงิน มี 3 แถว 💵 เงินสด · 📱 โอน/QR · 🔧 เครดิตช่าง ซึ่งบวกกันเท่า รวมทั้งหมด (#461) — ยอดขาย วิธีชำระ และสินค้าขายดีเป็นของ ทั้งวัน ส่วน "ตรวจนับเงินสดในลิ้นชัก" นับเฉพาะเงินสดของ กะที่เปิดอยู่ (นับตามกะ ไม่ใช่ตามวัน — แต่ละกะนับเฉพาะเงินที่เกิดในกะนั้น ตั้งแต่เปิดกะ) ตรงกับแท็บ 🔒 ปิดลิ้นชัก
ทำไมปุ่มปิดลิ้นชักกดไม่ได้ปุ่มจะกดได้เมื่อ ครบ 3 ข้อ: กรอกยอดนับจริงแล้ว · ไม่อยู่ในโหมดออฟไลน์ · ไม่มีรายการค้างส่ง (PR #456) ถ้ายังค้างอยู่ ระบบจะบอก ยังมี {N} รายการติดปัญหา / ค้างส่ง — ต้องส่งเข้าระบบให้หมดก่อนปิดกะ — รอให้ส่งหมด หรือให้เจ้าของร้านจัดการรายการที่ถูกปฏิเสธในหน้า รอเจ้าของ

เปิดกะถัดไปในวันเดียวกัน Next shift, same day

ระบบรองรับหลายกะต่อวัน (08 §11 · #452) — เช่น เปลี่ยนคนเฝ้าเคาน์เตอร์ตอนบ่าย

  1. ปิดกะปัจจุบันให้เรียบร้อยตามขั้นตอนด้านบน
  2. ที่หน้า ลิ้นชัก ทั้งสองแท็บจะมีการ์ด เปิดกะใหม่การ์ดบอก กรอกเงินตั้งต้นในลิ้นชักก่อนเริ่มขาย พร้อมช่องเงินตั้งต้นและปุ่มลัด
  3. นับเงินที่ส่งต่อในลิ้นชัก กรอก เงินตั้งต้น ฿ (หรือปุ่มลัด) → กด เปิดกะใหม่กลับไปแท็บ 💵 รายการเงิน ของกะใหม่ — ยอดเงินสดที่ควรมีนับเฉพาะเงินของกะใหม่นี้ (เริ่มจากเงินตั้งต้นที่กรอก)

ข้อความบนจอสาเหตุทำอย่างไร
กรุณาเปิดกะก่อนขาย · กรุณาเปิดกะก่อนรับชำระ · กรุณาเปิดกะก่อนยังไม่ได้เปิดกะ (ข้อความต่างกันตามงานที่ทำ)เปิดกะที่หน้า ลิ้นชัก (หัวข้อ 2)
สต็อกไม่พอ: + รายการสต็อกบนระบบไม่พอกับตะกร้าลดจำนวน หรือแจ้งเจ้าของร้านเช็กสต็อก
เกินวงเงินเครดิตยอดค้างช่างเกินวงเงินถามเจ้าของร้านก่อนกดยืนยันขาย

ระบบกำลังทำงานหนัก กรุณารอสักครู่ส่งคำขอถี่เกินรอสักครู่แล้วลองใหม่ อย่ากดรัว
คำขอก่อนหน้ากำลังดำเนินการ กรุณารอสักครู่บิลเดิมยังบันทึกไม่เสร็จรอ แล้วกดใหม่ — ระบบไม่ขายซ้ำ
ลิ้นชักปิดแล้ว ไม่สามารถบันทึกรายการเงินเพิ่มได้ / ปิดลิ้นชักแล้ว — ไม่สามารถบันทึกรายการเงินเพิ่มได้ปิดกะแล้วบันทึกหลังปิดกะไม่ได้ — ถ้าจะขายต่อ ให้เปิดกะใหม่ด้วยการ์ด เปิดกะใหม่ (หัวข้อ 7)
บิลนี้ไม่ได้อยู่ในกะที่เปิดอยู่ ยกเลิกบิลไม่ได้ กรุณาทำรายการคืนสินค้า (ใบลดหนี้) แทนยกเลิกบิลของกะก่อนใช้การคืนสินค้าแทน
บิลนี้มีใบลดหนี้แล้ว ไม่สามารถยกเลิกบิลได้บิลเคยคืนบางส่วนแล้วคืนรายการที่เหลือแทนการยกเลิก

กรุณาเข้าสู่ระบบ หรือกลับมาหน้าเข้าสู่ระบบเองsession หมดอายุ (ทุกวัน 04:00)เข้าสู่ระบบใหม่
