## 2. รอบนี้ทำอะไรไป ได้ผลอะไร

1. เจ้าของโปรเจกต์ตัดสิน (ข้อความ: *"ใช้ architecture แบบเดิมดีแล้ว แต่เขียน note ไว้เหตุผลที่ไม่ใช้"*)
2. `adr/0012` — สถานะ → Rejected, เพิ่มหัวข้อ "ผลการตัดสิน" (ตาราง 6 เหตุผล + ผลต่อเอกสารอื่น + สิ่งที่ยังมีค่า) ไว้**เหนือ**ข้อเสนอเดิม · หัวข้อคำถาม 5 ข้อเปลี่ยนเป็น "เตรียมไว้แต่ไม่ได้ส่ง"
3. `06` — header → Rejected/ประวัติ, ลบบรรทัด freeze
4. ถอน/แทน banner ใน 12 ไฟล์: `CLAUDE.md`, `AGENTS.md` (mirror — เพิ่มย่อหน้าเดียวกัน), `server/README.md`, `docs/00_LANE_PRIMER.md`, `00_INDEX` (banner + แถว 06), `00_BASICS` (ลบ), `01` (แทนด้วยหมายเหตุ §9), `02` (ลบ), `03` (แทน), `05` (ลบ), `04` (เติมผลในแถวรอบ 4), `adr/README` (แถว 0012 + หัวข้อ "ค้างใหญ่สุด")
5. `handoff_log/INDEX.md` — เพิ่มบรรทัดนี้, แก้บรรทัด couchdb-revision และ p2-schema ให้ไม่มี "ถ้า ADR-0012 ผ่าน"
6. ตรวจ: `grep -rn 0012` นอก 3 ไฟล์ประวัติ เหลือแต่ข้อความที่บอกว่า Rejected — ไม่มีคำว่า "Proposed / freeze / จนกว่าจะเคาะ" ค้าง
7. scrutinize (agent 1 ตัว อ่านเย็น): major 3 — ตารางเหตุผลอ้าง ticket ผิด verb (#18/#19/#21 ไม่ได้ "ย้าย"), ข้อความ "clamp ต่อ operation"
   กว้างเกิน (การขาย §7.1 strict/throw ไม่ clamp), ประโยค "ถ้าอยากมี 2 เครื่องขาย" ไม่มีที่มาและขัด `03 §7` (one-pos ถาวรอยู่แล้ว) —
   **แก้แล้วทั้ง 3** + minor/nit 7 ข้อ (AGENTS.md mirror, checkbox ค้าง, heading "Proposed" ค้าง, ตัวเลขไฟล์) — แก้แล้ว

## 3. ตัดสินใจอะไรไปบ้าง เพราะอะไร

| ทางเลือก | เลือก | เหตุผล | ใครตัดสิน |
|---|---|---|---|
| CouchDB (ก/ข) vs คง Postgres | **คง Postgres** | ดูตารางใน ADR-0012 — ใจความ: ก แย่กว่า Postgres ทุกข้อ, ข ยืนบน spike Flutter Web ที่ยังไม่พิสูจน์ + ทิ้ง #15 + เสี่ยง rubric, และ offline-first มีที่อยู่แล้วเป็นเฟส 2 | เจ้าของโปรเจกต์ |
| ส่งคำถาม 5 ข้อให้อาจารย์ก่อน vs ตัดสินเลย | **ตัดสินเลย** | เจ้าของโปรเจกต์เลือก — คำถามยังอยู่ท้าย ADR เผื่อกลับมา | เจ้าของโปรเจกต์ |
| ลบ `06` + ADR-0012 vs เก็บเป็น Rejected | **เก็บ** | ADR ที่ถูกปฏิเสธคือของมีค่า — กันวิเคราะห์ซ้ำ · `06 §9` อ้างบรรทัด Dart ของ invariant ที่คนเขียน #20–#24 ต้องใช้ | agent |
| เขียนเหตุผลไว้ที่ไหน | **บนสุดของ ADR-0012** ไม่ใช่ไฟล์ใหม่ | คนค้นหา "ทำไมไม่ใช้ CouchDB" จะเปิด ADR ก่อน · ไม่เพิ่มไฟล์ | agent |
| banner ใน `01`/`03`/`00_INDEX`/`LANE_PRIMER` ลบทิ้ง vs แทนด้วย 1–2 บรรทัด "ปฏิเสธแล้ว" | **แทน** (ส่วน `00_BASICS`/`02`/`05` ลบเพราะไม่มีอะไรเหลือให้พูด) | คนที่เห็น banner แดงเมื่อเช้าแล้วกลับมาเจอว่าหายไปเฉย ๆ จะไม่รู้ว่าจบยังไง | agent |

## 5. ยังไม่ชัวร์ / สมมติฐานที่ยังไม่พิสูจน์

* ❌ **อาจารย์รับทราบการตัดสินใจนี้หรือยัง — ไม่รู้** คำสั่ง CouchDB เป็นปากเปล่า และการปฏิเสธก็ยังไม่ได้แจ้งกลับ
  ถ้าอาจารย์ให้คะแนนตามหัวข้อ "ใช้ CouchDB" ทีมต้องมีตาราง ADR-0012 ไปอธิบาย
* ✅ ยืนยันแล้ว: ไม่มีไฟล์ไหนนอก 3 ไฟล์ประวัติที่ยังพูดถึง freeze หรือ Proposed (grep)
* ✅ ยืนยันแล้ว: ไม่มีอะไรถูกเขียนใน `server/` หรือ GitHub ระหว่างที่ freeze (ตาม handoff ก่อนหน้า §1) — ไม่มีของต้อง revert
