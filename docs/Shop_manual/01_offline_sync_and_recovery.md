# คู่มือการใช้งานระบบ: สถานะการซิงค์ การขายสำรองออฟไลน์ และการกู้คืนข้อมูล
**ระบบขายหน้าร้าน POS (Srisurart Autopart POS) — Phase 2**

---

## 1. แถบสถานะการเชื่อมต่อและการซิงค์ (Sync Status Bar)

บนแถบด้านบนสุดของหน้าจอ (TopBar) และแถบแจ้งเตือนใต้แถบบน ระบบจะมีตัวบ่งชี้สถานะการเชื่อมต่อแบบเรียลไทม์ 3 รูปแบบ (ตามข้อกำหนด Phase 2 Option A):

| สถานะ | สี / สัญลักษณ์ | ความหมายและการทำงาน |
|---|---|---|
| **`ออนไลน์`** | จุดสีเขียว `●` | เครื่อง POS เชื่อมต่อกับเซิร์ฟเวอร์คลาวด์สมบูรณ์ รายการขาย การคืนเงิน และการปรับสต็อกจะถูกบันทึกและส่งไปยังเซิร์ฟเวอร์ทันที |
| **`ออฟไลน์ (ขายสำรอง)`** | จุดสีส้มอำพัน `●` / แถบสีส้ม | เครื่อง POS ขาดการเชื่อมต่ออินเทอร์เน็ต ระบบจะสลับเข้าสู่โหมดขายสำรองโดยอัตโนมัติ **สามารถขายสินค้าและพิมพ์ใบเสร็จให้ลูกค้าได้ตามปกติ** ข้อมูลจะถูกบันทึกลงในเครื่อง และส่งขึ้นเซิร์ฟเวอร์ทันทีที่เน็ตกลับมา |
| **`กำลังส่งข้อมูล...`** | ไอคอนหมุนสีฟ้า `⟳` | ระบบตรวจพบสัญญาณอินเทอร์เน็ต และกำลังทยอยส่งรายการขาย/คืน/เปิดกะที่ค้างอยู่ในเครื่องขึ้นเซิร์ฟเวอร์ พร้อมระบุจำนวนรายการที่กำลังรอส่ง เช่น `(ค้างส่ง 3)` |

> ⚠️ **หมายเหตุสำคัญเกี่ยวกับการขายออฟไลน์:**  
> ในระบบ Phase 2 นี้ **สินค้าทุกรายการสามารถขายในโหมดออฟไลน์ได้** โดยไม่มีข้อจำกัด "ป้ายเทาขายออฟไลน์ไม่ได้" อีกต่อไป (ตัดกฎ `offlineOk` ทิ้งตามมติสถาปัตยกรรม D3 และ ADR-0004)

## 2. การแจ้งเตือนและหน้า "รอเจ้าของ" (Owner Review)

เมื่อมีรายการขายหรือรายการซิงค์ที่ต้องได้รับการตรวจสอบจากเจ้าของร้าน ระบบจะแสดงการแจ้งเตือนดังนี้:
1. **ป้ายเตือน `รอตรวจสอบ (N)` บนแถบด้านบน (TopBar):** แสดงจำนวนรายการที่ติดปัญหาหรือต้องรอการตัดสินใจ
2. **แถบเตือนสีแดงใต้ TopBar:** มีข้อความ *"มีรายการรอเจ้าของร้านตรวจสอบ (N รายการ)"* พร้อมปุ่ม *"ดูรายการ"*
3. **ป้ายตัวเลขสีแดงบนเมนูด้านซ้าย:** เมนู **"รอเจ้าของ"** จะแสดงตัวเลขรายการค้าง

### เมื่อกดเข้าไปที่หน้า "รอเจ้าของ" จะมี 2 แท็บ:
- **แท็บ 1: ถูกปฏิเสธ / ค้าง (Rejected / Stuck):**
  - รายการขายช่วงออฟไลน์ที่ไม่สามารถนำเข้าระบบหลักได้อัตโนมัติ (เช่น สต็อกบนเซิร์ฟเวอร์ไม่เพียงพอ หรือมีการขายตัดหน้า)
  - เจ้าของร้านสามารถตรวจสอบรายละเอียดบิล สินค้าที่ขาย และเลือกได้ว่าจะ:
    - **`ส่งใหม่`**: ลองส่งรายการเข้าระบบอีกครั้งด้วยรหัสเดิม (ห้ามเปลี่ยนเลขที่บิล)
    - **`ทิ้งรายการ`**: ยกเลิกรายการออกจากคิว โดยต้องระบุเหตุผลประกอบอย่างชัดเจน
- **แท็บ 2: รอตรวจ (Pending Review):**
  - รายการสำคัญที่ระบบบันทึกเข้าระบบแล้ว แต่ต้องให้เจ้าของร้านรับทราบ เช่น:
    - การยกเลิกบิลตอนออฟไลน์ (`void_offline`)
    - การขายเกินวงเงินเครดิตช่าง (`credit_override`)
    - การปิดกะอัตโนมัติโดยไม่ได้นับเงิน (`shift_uncounted`)
    - เวลาเครื่องไม่ตรงกับระบบ (`date_flag`)
  - เจ้าของร้านตรวจสอบแล้วกดปุ่ม **`ตรวจแล้ว`** เพื่อเคลียร์รายการ

## 3. ขั้นตอนปฏิบัติกรณีฉุกเฉิน: หน่วยความจำในเครื่องสูญหาย (Storage Lost — F8 & X7)

### 3.1 สาเหตุที่อาจเกิดขึ้น
- แคชของเบราว์เซอร์หรือ IndexedDB ถูกล้าง (Browser Clear Data / Storage Reset)
- อุปกรณ์ POS เสียหาย เปลี่ยนคอมพิวเตอร์เครื่องใหม่ หรือลงระบบปฏิบัติการใหม่

### 3.2 สิ่งที่เกิดขึ้นตามสถาปัตยกรรม (F8)
- ข้อมูลคิวที่ยังไม่ได้ซิงค์ (Outbox) และตัวนับเลขที่เอกสารในเครื่องจะสูญหาย
- ระบบไม่อนุญาตให้ออกรหัสเดิมซ้ำ ดังนั้น **เจ้าของร้านจะต้องลงทะเบียนเครื่องใหม่ (Re-enrol) เสมอ**
- เครื่องที่ลงทะเบียนใหม่จะได้รับรหัสเครื่องใหม่ (`device_no` ใหม่) เสมอ เช่น จากเครื่องเดิมเบอร์ `01` จะกลายเป็นเบอร์ `02`

### 3.3 ขั้นตอนการคีย์บิลย้อนหลังจากใบเสร็จกระดาษ (F8 & X7)
หากมีรายการขายที่เกิดขึ้นระหว่างออฟไลน์ก่อนที่ข้อมูลเครื่องจะหาย แคชเชียร์หรือเจ้าของร้านต้องนำ**สำเนาใบเสร็จกระดาษ**มาคีย์เข้าระบบย้อนหลังตามขั้นตอนดังนี้:

1. **เข้าสู่หน้าขายสินค้า:** คีย์สินค้า ราคา และจำนวนตามที่ระบุในใบเสร็จกระดาษให้ตรงกันทุกประการ
2. **⚠️ ข้อสำคัญที่สุดเรื่องเลขที่เอกสาร (X7):**
   - เมื่อกดบันทึกการขาย ระบบจะออก**เลขที่เอกสารใหม่**ตามรอบของเครื่องใหม่ (เช่น ได้เลข `RC670919_02_0001` แทนที่จะเป็นเลขเดิมบนใบกระดาษ)
   - **ห้ามพยายามแก้ไขเลขที่เอกสารให้ตรงกับใบเดิม** เพราะระบบควบคุมความถูกต้องของเลขเอกสารตามเครื่อง (`device_no` ต้องตรงกับ `did`)
3. **การบันทึกเลขเดิมในหมายเหตุ (X7):**
   - **ต้องพิมพ์เลขที่เอกสารเดิมจากใบเสร็จกระดาษลงในช่อง "หมายเหตุ" ของบิลเสมอ** (เช่น ใส่หมายเหตุ: *"คีย์ย้อนหลังจากใบเสร็จเดิม RC670919_01_0045 เนื่องจากเครื่องรีเซ็ต"*)
   - การบันทึกเลขเดิมในหมายเหตุจะทำให้ฝ่ายบัญชีและเจ้าของร้านสามารถตรวจสอบย้อนกลับไปยังใบเสร็จกระดาษและสอบทานสต็อกได้อย่างถูกต้องครบถ้วน
